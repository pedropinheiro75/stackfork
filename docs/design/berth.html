One App chip per version

Live: a link. Port pending: "App · port assigned on start". Stopped: "App" in grey. Host app known only from learn: "App · on host", with the command in the tooltip and the ⋯ menu.

Sort and filter

Projects with a live version first, then activity, then name. Filter and Running only hide versions inside their project; the header keeps "3 versions · 2 hidden".

No start-all

The project ⋯ offers Start a branch…, Show in Repos and Copy repo path. Starting or stopping stays one click per stack.

State system

Five states, always glyph + word. Red only for something broken or a button that deletes; a stopped stack is grey.

ok · Running attention · Partial failed · Exited busy · Starting off · Stopped

Rules

Mono means data

Branches, paths, URLs, ports, commands and SHAs are mono. Labels and buttons are sans.

Red budget

Red appears only next to something broken or a control that deletes.

One filled button

Each view has at most one primary. Everything else is secondary, ghost or in the menu.

No horizontal scroll at 400 px

Rows become two lines, actions collapse to one button and the overflow, the lane graph hides.
